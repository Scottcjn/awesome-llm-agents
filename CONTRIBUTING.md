# Contributing to awesome-llm-agents

Thank you for your interest in contributing! This list focuses on LLM-powered agents, frameworks, and applications.

## How to Contribute

### Adding a New Entry

1. **Fork the repository** and clone it locally
2. **Add your entry** to the appropriate section in `README.md`
3. **Follow the format**: `- [Project Name](link) - Brief description`
4. **Verify LLM focus**: Entries should use or support LLM-based agents
5. **Submit a Pull Request** with a clear description

### What Qualifies

- **Agent frameworks**: LangChain, AutoGen, CrewAI, etc.
- **LLM tools**: Prompt engineering, RAG, fine-tuning for agents
- **Applications**: Real-world LLM agent implementations
- **Research**: Papers on LLM agents and multi-agent systems
- **Learning**: Tutorials and guides for LLM agent development

### Guidelines

- **LLM-focused**: Must relate to large language model agents
- **Quality projects**: Prefer well-maintained, documented projects
- **Concise descriptions**: Clearly state what the resource offers
- **Alphabetical order**: Keep lists sorted within sections
- **Working links**: Verify all URLs work before submitting

### Pull Request Checklist

- [ ] Entry follows the existing format
- [ ] Related to LLM-based agents
- [ ] Project is actively maintained (if applicable)
- [ ] Added to the correct section
- [ ] No duplicate entries

## Code of Conduct

- Be respectful and inclusive
- Foster a collaborative community
- Help others learn and grow

## Questions?

Open an issue for discussions or clarifications.
