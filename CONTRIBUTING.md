# Contributing to Awesome LLM Agent Frameworks

Thanks for improving this curated list of LLM frameworks and agent tools!

## Quick Start

1. Fork this repository
2. Add your framework to the appropriate category
3. Open a Pull Request

## Adding a Framework

### Format

```markdown
- [Framework Name](https://github.com/link) - One-line description

  X stars · X forks · X contributors · X issues · Language · License

  - Feature 1
  - Feature 2
  - Feature 3
```

### Required Information

- **Name with GitHub link**
- **Brief description** (one line)
- **Stats**: stars, forks, contributors, issues
- **Language** (Python, TypeScript, etc.)
- **License** (MIT, Apache, etc.)
- **3-5 key features** as bullet points

## Categories

Organize your submission under:

- **Frameworks** - Full agent frameworks (CrewAI, Langchain, etc.)
- **Tools** - Agent development utilities
- **Memory** - Agent memory systems
- **Evaluation** - Agent testing/benchmarking
- **Observability** - Agent monitoring/debugging

## Quality Criteria

**Accepted:**
- ✅ Active projects (commits in last 6 months)
- ✅ Public GitHub repository
- ✅ Real usage/adoption (100+ stars minimum)
- ✅ Documentation available

**Not accepted:**
- ❌ Inactive projects (12+ months no updates)
- ❌ Private or invite-only repositories
- ❌ Example/demo projects without real functionality

## Pull Request Checklist

- [ ] Framework added to correct category
- [ ] Stats are current and accurate
- [ ] Features are actually implemented (not planned)
- [ ] Links work and point to correct repo
- [ ] Format matches existing entries

## Updating Existing Entries

You can also:
- Update outdated stats
- Add missing features
- Fix broken links
- Improve descriptions
